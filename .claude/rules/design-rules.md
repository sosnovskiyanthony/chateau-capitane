# Design Rules

Placeholder defaults until real brand assets exist — replace once a style guide, logo, or photography set is provided.

- Palette: neutral stone/cream base (Tailwind `stone`/`zinc` scale), one accent color max. No more than 3 colors per page excluding neutrals.
- Typography: one serif for headings, one sans for body. Max 2 font families total.
- Spacing: use Tailwind's default scale only — no arbitrary px values unless matching a reference screenshot exactly.
- Imagery: real photography over illustration/stock where possible; every image needs specific, non-generic alt text.
- Tone: elegant, warm, concise copy — avoid marketing filler ("world-class", "unparalleled", "best-in-class").
- Responsive: design mobile-first; verify at 375px, 768px, and 1280px.
- Reuse: check for an existing component/pattern before creating a new one.
