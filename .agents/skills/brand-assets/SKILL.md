# Restaurant brand assets with Codex

Research the brief, existing logo and tokens, `docs/design.md`, and supplied references. Plan the actual deliverables, sizes, use context, visual direction, and review criteria before generating. Preserve the current captain/anchor logo and Bodoni Moda/Albert Sans pairing unless a rebrand is explicitly requested.

Use an available image-generation tool for requested raster art or visual concepts; use the original SVG/code assets for vector logo adjustments. For website concept references, produce separate readable section images when requested detail requires them, with a consistent palette and realistic implementation scale. Do not automatically generate every section for a minor UI edit.

Keep brand boards sparse and legible: logo usage, type hierarchy, palette, and useful applications. Deliver usable assets at requested dimensions and inspect them for crop, text, consistency, and transparency. Generated decorative art is not evidence of the actual restaurant, menu, or events. Save approved assets in appropriate project paths; do not change the live site merely because a concept was generated.
